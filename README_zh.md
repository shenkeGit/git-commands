# Git Commands Plugin

通过简单的命令简化您的 git 工作流程，实现提交、推送和合并分支。

## 概述

Git Commands Plugin 自动化常见的 git 操作，减少上下文切换和手动命令执行。无需运行多个 git 命令，只需使用单个斜杠命令即可处理整个工作流程。

## 命令

### `/git-commit`

根据已暂存和未暂存的更改，自动生成提交消息来创建 git commit。

**功能说明：**
1. 分析当前 git 状态
2. 审查已暂存和未暂存的更改
3. 检查最近的提交消息以匹配您仓库的风格
4. 起草合适的提交消息
5. 暂存相关文件
6. 创建提交

**使用方法：**
```bash
/git-commit
```

**特性：**
- 自动起草符合您仓库风格的提交消息
- 遵循 conventional commit 规范
- 避免提交包含机密的文件（.env、credentials.json）
- 在 `dev` 分支上提交时，提交信息末尾追加 `#relese#`，用于触发自动升级

### `/git-push`

一步完成提交并推送当前分支到 origin。

**功能说明：**
1. 暂存并使用合适的消息提交更改
2. 将当前分支推送到 origin（如需，设置上游跟踪）

**使用方法：**
```bash
/git-push
```

**特性：**
- 单步完成提交与推送
- 在 `dev` 分支上提交时，提交信息末尾追加 `#relese#`，用于触发自动升级

### `/git-merge`

将当前分支合并到指定的目标分支。

**功能说明：**
1. 记录当前分支（源分支）
2. 切换到目标分支（由参数提供）
3. 将源分支合并到目标分支
4. 将目标分支推送到 origin
5. 切回原始的源分支

**使用方法：**
```bash
/git-merge <目标分支>
```

**示例：**
```bash
# 将当前分支（如 dev）合并到 main
/git-merge main
```

**特性：**
- 将当前分支合并到作为参数指定的目标分支
- 合并后推送目标分支
- 完成后切回原分支
- 出现合并冲突时停止并报告，不强制提交

## `#relese#` 触发机制

当在 `dev` 分支上提交时（通过 `/git-commit` 或 `/git-push`），提交信息末尾会附带 `#relese#`。该标记用于被 CI 识别并触发自动升级/发布。其他分支的提交不附带该标记。

## 安装

这是一个 Claude Code 插件。在 Claude Code 中将 `git-commands` 目录启用为插件，即可使用 `/git-commit`、`/git-push` 和 `/git-merge` 斜杠命令。

或者，将 `commands/` 中的文件直接复制到项目的 `.claude/commands/` 目录，作为散装自定义命令使用。

## 要求

- Git 必须已安装并配置
- 仓库必须是带有名为 `origin` 远程仓库的 git 仓库（用于 `/git-push` 和 `/git-merge`）

## 故障排除

### `/git-commit` 创建空提交
- 确保您有未暂存或已暂存的更改
- 运行 `git status` 以验证更改存在

### `/git-push` 推送失败
- 确保仓库有名为 `origin` 的远程仓库
- 运行 `git remote -v` 验证

### `/git-merge` 报告冲突
- 手动解决冲突后，重新运行 `/git-merge`
- 该命令遇到冲突会停止，不强制提交
